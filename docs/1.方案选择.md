# 闲置安卓手机改监控摄像头

将淘汰的老旧安卓手机改造为安防监控，不仅能废物利用，其摄像头素质往往也吊打市面上的百元廉价监控。本文梳理了从小白到极客的完整落地方案。

## 方案一：开箱即用的“小白”路线

适合不想折腾代码，只需快速搭建局域网/公网监控的用户。

- **阿福管家 (Alfred Camera)**：体验最好的傻瓜式应用。支持双端登录（采集和观看），自带移动侦测报警和双向对讲。
- **掌上看家 (AtHome)**：国内老牌软件，支持多端查看和云端录制。
- **IP Webcam**：极客入门首选。在旧手机本地拉起一个 HTTP Server，局域网内通过浏览器输入 IP 即可直接查看 MJPEG 视频流，并提供丰富的后台控制接口。

## 方案二：开发者的“硬核”路线

适合拥有公网服务器/家庭服务器，追求极致隐私和自定义开发的极客。

- **WebRTC (纯前端方案)**：利用 `navigator.mediaDevices` 采集画面，通过 `simple-peer` 等库建立 P2P 连接。延迟极低，开发成本最低。
- **RTSP 推流 (直播流方案)**：在安卓端运行 `RootEncoder` 等 RTSP 服务端应用，将流推至后端的 Node-Media-Server。适合需要极高并发（多人同时观看）的场景。
- **云边混合终极架构 (推荐)**：
  - **边缘端**：旧手机连接 Wi-Fi，运行 WebRTC 采集端。家庭服务器（Node.js）作为信令中转。
  - **网络层**：全设备接入 Tailscale 组建虚拟大内网，实现内网直连穿透。
  - **公网层**：阿里云轻量服务器部署 Nginx 反向代理与 Coturn（STUN/TURN）服务，保障外部无 VPN 环境下的随时随地访问。
